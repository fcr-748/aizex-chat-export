# Aizex 聊天记录导出（aizex聊天记录导出）

> 在浏览器控制台里一键导出 Aizex 合租面板（OpenAI 风格镜像）中的全部聊天记录。
> 纯前端脚本，零安装、零依赖，数据只保存在你自己电脑上。

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/Platform-Chrome%20%2F%20Edge-blue)](https://www.google.com/chrome/)

## 这是什么

Aizex 这类 OpenAI 风格镜像面板（`*.memofun.net` / `*.aizex.net`）的网页里没有"一键导出全部聊天"的功能，只能一条一条手动导出。

这个项目提供几个**粘贴到浏览器控制台即可运行**的脚本，自动完成：

- 扫描侧边栏的全部会话（自动向下滚动加载更多）
- 逐条打开会话，抓取完整内容（包括被折叠的早期消息）
- 增量续跑：自动跳过已导出的会话，只导出缺失的，随时中断、随时接续
- 输出 `aizex_export.json`（完整备份）、`00_索引.md`（目录）、每个会话一份 `.md`

## 快速开始

1. 用 Chrome 或 Edge 登录你的 Aizex 面板，进入聊天页面（左侧能看到会话列表）
2. 按 `F12` 打开开发者工具，切到 **Console（控制台）**
3. 打开 [src/aizex_export_v31_snippet.js](src/aizex_export_v31_snippet.js)，全选复制全部内容
4. 粘贴到控制台，按回车
5. 按右上角面板提示：选保存文件夹 → 开始导出

> 推荐直接使用 **v3.1** 脚本（最稳定）。各版本差异见 [CHANGELOG.md](CHANGELOG.md) 和 [docs](docs)。

## 特性

- **零安装**：不需要 Node / Python / 任何依赖，只用浏览器自带能力
- **增量续跑**：扫描文件夹里已有的 `.md`，跳过已导出的会话，只导缺失的；重启后自动接续
- **完整抓取**：打开会话后反复向上滚动，触发"加载更早消息"，不丢开头
- **接口直连（自动）**：尝试识别面板后端接口直接拉取；候选接口会先验证，可疑接口自动退回页面抓取
- **坏文件自愈**：自动识别被污染的无效文件（例如统计接口返回值）并重新导出
- **合并保存**：每次运行把新结果合并进已有的索引和 JSON，不会因重启而覆盖丢失
- **隐私安全**：所有代码在你自己的浏览器里运行，不上传任何数据；仓库内不含任何个人信息

## 导出结果

- `aizex_export.json`：完整结构化备份（含全部消息，可用于后续迁移 / 格式转换）
- `00_索引.md`：所有已导出会话的目录
- `标题_会话ID前8位.md`：每个会话一份可读 Markdown

## 使用注意事项

- 运行期间**保持标签页在前台**，浏览器会对后台标签页限速甚至暂停
- 如果中途提示"登录失效 / 被踢"（共享账号池常见），重新登录后重新运行即可，会自动接续
- 建议用 Chrome / Edge（支持"选择文件夹"，增量续跑依赖它）

## 安全说明

- 脚本只在你自己的浏览器里运行，**不会把任何数据发送到外部**
- 不要求也不保存你的账号密码；登录态由浏览器自身管理
- 导出的数据文件保存在你自己电脑上，请妥善保管
