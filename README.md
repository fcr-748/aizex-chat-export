# Aizex 聊天记录导出（aizex聊天记录导出）

> 一键把 Aizex 合租面板（OpenAI 风格镜像）里的全部聊天记录导出到你自己电脑上。
> 两种用法：浏览器控制台脚本（零安装）或 Chrome / Edge 扩展（点一下就行）。

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/Platform-Chrome%20%2F%20Edge-blue)](https://www.google.com/chrome/)

## 这是什么

Aizex 这类 OpenAI 风格镜像面板（`*.memofun.net` / `*.aizex.net`）的网页里没有"一键导出全部聊天"，只能一条一条手动导出。

本项目自动完成：

- 扫描侧边栏的全部会话（自动滚动加载更多）
- 逐条打开会话，抓取完整内容，**包括被折叠起来的早期消息**
- 优先走面板后端接口（`/backend-api/...`），接口不通时自动退回页面解析
- 增量续跑：跳过已导出的会话，只补缺失的，随时中断、随时接续
- 输出 `aizex_export.json`（完整备份）+ `00_索引.md`（目录）+ 每个会话一份 `.md`

## 两种用法

### 用法 A：Chrome / Edge 扩展（省事）

用 [extension/](extension/) 里的扩展：加载已解压的扩展 → 打开面板聊天页 → 点扩展图标 → 注入 → 选保存文件夹 → 开始导出。
细节见 [extension/README.md](extension/README.md)。

### 用法 B：控制台脚本（零安装）

1. 用 Chrome 或 Edge 登录你的面板，进入聊天页面（左侧能看到会话列表）
2. 按 `F12` 打开开发者工具，切到 **Console（控制台）**
3. 打开 [src/aizex_export_v340.js](src/aizex_export_v340.js)，全选复制全部内容
4. 粘贴到控制台，按回车
5. 按页面右上角浮窗的提示：选保存文件夹 → 开始导出

> 换新面板时，可以先粘贴 [tools/识别面板类型.js](tools/识别面板类型.js) 判断这个站点受不受支持。
> 老版本脚本（v1 / v2 / v3 / v3.1）留在 [src/](src/) 里只作对照，不推荐使用。

## 特性（当前 v3.40）

- **零安装**：控制台脚本不需要 Node / Python / 任何依赖，只用浏览器自带能力
- **完整抓取**：优先接口直连；接口不可用时点开面板真实的折叠控件（`span.nextc-batch-trigger-action` 等）逐批展开，直到面板不再显示折叠块
- **完整性自检**：读面板自己标的"共 N 轮"，还有残留折叠就再开一轮展开，结果写进 `_诊断_导出.md`
- **双源合并**：后端接口一份 + 页面展开一份，取更全的，另一份独有的消息附在文末
- **增量续跑**：`_已完成清单.txt` 记录进度，中途停了再跑不重头来；`_待补清单.txt` 记录没抓全的
- **内容保护**：新抓的比已有文件少时不覆盖已有内容
- **格式保真**：代码块带语言围栏、表格转标准 Markdown、列表按层级缩进、行内格式保留
- **公式保真**：以接口的原始 Markdown 为准（公式是 LaTeX 原文），`\[…\]` / `\(…\)` 统一换成预览器认的 `$$…$$` / `$…$`；只有独占一行的 `\[…\]` 才做独立块，句中 / 跨行的一律按行内，不会在段落中间劈出公式把后面的 `$` 带歪
- **每轮清单很快**：接口能列全就直接用，不再重复滚侧边栏（那一趟能省几分钟）
- **每轮按类型报清楚**：新对话 / 面板上有更新 / 旧格式升级，状态栏和诊断都分开写
- **缺的开头会补到开头**：接口没给、页面版有的那段按位置补在正文开头，不再丢到文末附录；文件头另有一行记录接口/页面各自抓了多少条
- **图片下载失败会兜底**：用同一条消息里页面已渲染的地址再试一次，两条路都不通才提示
- **折叠一定点开**：打开后先等折叠块渲染出来再判断，且预算按轮数放大，不会中途掐断；没抓全的文件会标记为待补、下次自动重抓
- **两种图片指针都认**（`file-service://` 与 `sediment://`），下载不到的图会在原地写明原因
- **界面图标不会被当成会话图片**：只从消息节点里捞图，小图标/Logo/按钮图一律跳过
- **附件就地标注**：图片/文件放在它出现在的那条消息里，写 ![](images/xxx.png) + > 附件: 名字，不再堆到文末
- **接口按 current_node 取主链**：重新生成 / 编辑过的会话也能取到页面上真正显示的那条，不会因为走错分支少消息
- **页面版公式按 KaTeX 的 HTML 结构反推**：分数（`\frac{}{}`）、`\text{…}` 能还原回来，认不出的结构退回普通文字
- **不"空格变换行"**：按 DOM 结构换行，浏览器自动折的行不会变成换行
- **图片下载**：收集会话里的图片并尝试下载到 `images/`，下不到的保留指针并在报告里标注
- **按会话 ID 去重**：会话改过标题也不会变成两份文件，历史遗留的重复文件挪进 `_duplicates/`（不删除）
- **按更新时间增量**：从接口读每条的 `update_time` 存进 `_同步台账.json`；下次运行只重抓"面板上有更新"的会话
- **一键打包**：结束时自动生成 `归档_日期-时间.zip`（含 md + images + 索引 + manifest + 归档说明）
- **本地桥接（可选）**：跑起 [tools/aizex_bridge_server.js](tools/aizex_bridge_server.js) 后，脚本直接写入指定文件夹，不用每次手动选
- **隐私安全**：所有代码在你自己的浏览器里运行，不上传任何数据

## 导出结果

```

├── aizex_export.json           # 完整结构化备份（含全部消息）

```

## 使用注意事项

- 运行期间**保持标签页在前台**，浏览器会对后台标签页限速甚至暂停
- 若中途提示"登录失效 / 被踢"（共享账号池常见），重新登录后重新运行即可，会自动接续
- 建议用 Chrome / Edge：控制台脚本的"选择文件夹"和增量续跑依赖它们

## 安全说明

- 脚本和扩展都只在你自己的浏览器里运行，**不会把任何数据发送到外部**
- 不要求也不保存你的账号密码；登录态由浏览器自身管理
- 导出的数据文件保存在你自己电脑上，请妥善保管
- 仓库里的 `extension/licensing.js` 与 `tools/keygen.js` 用占位密钥，自己发布前改成自己的密钥
