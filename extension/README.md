# 对话记录归档助手（Chrome / Edge 扩展）

导出脚本本体在 `src/aizex_export.js`（同 `../src/aizex_export_v341.js`，v3.41）。
扩展只是把它包起来：点一下图标就注入，并加上免费版 / 专业版的门禁。

## 一、这个扩展能做什么

- 一键把面板里的全部对话导出到本地（完整版能力，含被折叠的历史轮次）
- **免费版**：单次最多导出 30 条会话，**不展开折叠的历史轮次**
- **专业版**：全量导出 + 自动展开折叠历史 + 断点续跑（靠激活码解锁）
- 激活码离线校验，不依赖服务器；数据只写本地，不上传任何东西

文件结构：

```
manifest.json          扩展清单（MV3）
popup.html / popup.js  点图标后的弹窗：授权状态 + 激活 + 注入按钮
licensing.js           激活码校验（HMAC 签名，离线可验）
src/aizex_export.js    导出脚本本体（v3.41 + 授权门禁）
```

## 二、2 分钟自测（免费版 → 专业版）

1. `chrome://extensions` → 打开右上角"开发者模式" → "加载已解压的扩展程序" → 选本文件夹
2. 打开面板聊天页 → 点扩展图标：
   - 应该看到标签是 **免费版**，下面写着"最多导出 30 条…"
   - 页面右上角浮窗标题也会显示 **· 免费版**
3. 点"设备码"按钮，能看到一串 16 位设备码（用于绑定记录）
4. 用 `../tools/keygen.js` 生成一个激活码，粘进弹窗输入框 → 点"激活"
   - 标签变成 **专业版**，再点注入，浮窗标题会显示 **· 专业版**，此时全量导出 + 折叠展开都开
5. 点"解除本机激活"可退回免费版，验证降级也正常

## 三、怎么生成激活码

```bash
cd ../tools
node keygen.js --plan P --count 20 --out keys_pro.txt     # 专业版（远期日期代表永久）20 个
node keygen.js --plan Y --count 50 --out keys_year.txt    # 年费版（365 天）50 个
node keygen.js --plan T --count 100 --out keys_trial.txt  # 体验版（30 天）100 个
node test_licensing.mjs                                   # 7 项自测（含过期码 / 篡改码）
```

生成是全离线的，不需要服务器。卖之前记得先改密钥，见下一节。

> ⚠️ 本仓库里的 `licensing.js` 和 `keygen.js` 用的是占位密钥 `CHANGE_ME_TO_YOUR_OWN_SECRET`。
> 自己发布前把两处都改成同一个自己的密钥；生成的激活码文件（`keys_*.txt`）不要提交到公开仓库。

## 五、上架 Chrome 商店（可选，1-3 天审核）

1. 注册开发者账号：一次性 **$5**（约 ¥36），用 Google 账号
2. 打包：把本文件夹压缩成 zip（或让商店自动打包）
3. 填商店信息：名称、简介、截图（建议放"导出前后对比"和"浮窗界面"两张）
4. 隐私说明（过审关键）：**不收集、不上传任何用户对话数据；仅本地写入用户选择的文件夹；仅存储本地激活码状态**
5. 审核通过后拿到安装链接，把它写进 `BUY_URL` 的落地页

> 不打算上架也行：直接把文件夹 zip 发给对方，让他按第二节的"加载已解压的扩展程序"装上。

## 六、为什么这样设计（备忘）

- **导出脚本跑在页面主世界（`world: 'MAIN'`）**：它要用相对路径调面板自己的接口、要带 cookie，用扩展自己的世界会跨域失败
- **授权门禁只卡两件事**：限制条数、禁止折叠展开——这两点都明显影响导出质量，用户有动力升级
- **离线验签**：卖一次性卡密最省事，不用维护服务器；代价是无法吊销（要吊销就得上在线校验）
- **前端挡不住破解**：这点必须接受；真正的护城河是"面板改版后我帮你修"
