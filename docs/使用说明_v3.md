# 使用说明 v3

> 当前推荐使用 v3.1：`src/aizex_export_v31_snippet.js`。本文件为 v3 说明。

## v3 相比 v2

- **增量续跑**：扫描文件夹里已有的 `.md`，自动跳过已导出的会话，只导出缺失的；随时中断、随时接续
- **修复开头缺失**：打开会话后反复向上滚动，触发"加载更早消息"，抓全被折叠的早期内容
- **合并保存**：每次结束把新结果合并进已有的索引和 JSON，不会因重启而覆盖丢失
- 增加"强制重导关键词"：想重新导出某些已导出的会话时，在输入框填标题关键词即可

## 步骤

1. 用 Chrome / Edge 登录面板，进入聊天页面（若页面上还有旧面板，先刷新）
2. 按 `F12`，点 **Console（控制台）**
3. 打开 `src/aizex_export_v3_snippet.js`，全选复制全部内容
4. 粘贴进控制台，按回车
5. 右上角面板：选**上次用的同一个文件夹**，保持"跳过已导出的会话"打勾，点开始

## 提示

- 保持标签页在前台
- 中途"登录失效 / 被踢"：重新登录后重跑即可，自动接续
- 面板会显示"面板共 N 个会话；文件夹里已有 M 个文件；本次需导出 K 个"
