## 一、上一版的日志说了什么

```
/files/…/download 200 (application/json)
```

两个信息：**请求成功**（200），而且**内容是 JSON**，不是二进制流。也就是说图片在 JSON 里，但字段名不是代码认识的 `download_url` / `url` / `file.download_url` 这三个，于是白跑一趟。

## 二、这一版怎么找

按顺序挖：

1. 常见直链字段：`download_url`、`downloadUrl`、`url`、`file_url`、`fileUrl`、`signed_url`、`signedUrl`、`href`、`link`、`path`
2. base64 字段：`b64_json`、`b64`、`base64`、`base64_data`、`data_base64`、`image_base64`（OpenAI 系镜像常见这种）
3. 前两步都没有 → **递归翻整段 JSON**，找第一个像地址（`http…`、`/…`）或 `data:image/…` 的字符串

拿到之后：地址就带着登录态去拉；base64 就转成数据流；最后用**文件头魔数**判断类型存盘（png/jpg/gif/webp/pdf/bmp）。仍然只是"不是图片"（比如登录页）才跳过。
