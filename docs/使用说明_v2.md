# 使用说明 v2

> 当前推荐使用 v3.1：`src/aizex_export_v31_snippet.js`。本文件为 v2 说明。

## v2 相比 v1

- 新增"接口直连"尝试：观察页面请求，找到会话接口就全量拉取（快、完整）
- 找不到接口就用页面抓取，修复了：空回复、提前停住、漏会话的问题
- 支持流式（SSE / JSONL）响应解析；解析失败保留原始内容

## 步骤

1. 用 Chrome / Edge 登录面板，进入聊天页面
2. 按 `F12`，点 **Console（控制台）**
3. 打开 `src/aizex_export_v2_snippet.js`，全选复制全部内容
4. 粘贴进控制台，按回车
5. 选文件夹 → 开始导出；**保持标签页在前台**

## 已知问题（v3 / v3.1 已修复）

- 不能增量续跑，每次都要全部重来
- 早期消息被折叠时可能抓不全开头
- 接口识别可能误判统计接口（v3.1 彻底修复）
