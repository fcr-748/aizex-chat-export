# 使用说明 v3.29（控制台脚本，当前推荐版本）

脚本文件：[src/aizex_export_v329.js](../src/aizex_export_v329.js)

## 一、这一版修的公式坑

### 判据：只有"自己独占一行"的 `\[ … \]` 才当独立行公式

ChatGPT 的原文里，`\[` 有时在句尾、内容另起一行、`\]` 又在下一行开头，整段还夹在句子中间：

```
但 \[
0,1
\] 里面的点是**不可列无穷多个**。
```

v3.28 只要看到 `\[…\]` 就插一个 `$$` 块，于是在段落中间劈出公式，把后面的 `$` 全部带歪——预览里就是散架的 `$$ 0,1 $$`，甚至报 `KaTeX parse error: Expected 'EOF', got '#'`（一个 `$` 把后面整段正文都吞进公式里了）。

v3.29 的判据：

| 输入 | 输出 |
| --- | --- |
| `\[` 独占一行 开头、`\]` 独占一行 结尾 | `$$`（独立块）+ 公式体 + `$$` |
| 其它任何情况（夹在句中、自己跨行） | `$ 公式 $` 行内，跨行的内容压成一行 |
| `\( … \)` | `$ 公式 $` |

修完的效果：

```
但 $[0,1]$ 里面的点是**不可列无穷多个**。

所以不能把

$$
P([0,1])
$$
```

### 没有公式原文时不再假装成公式

面板的 KaTeX 只输出 HTML（没有 mathml/annotation 层），页面 DOM 里拿到的是排版结果（`n=1⋃∞An∈F` 这类）。以前会把它包成 `$$…$$`，预览就是一堆乱码公式；现在这种只当普通文字写。

## 二、文末附录不再抄重复内容

合并两份来源时，旧版用"前 50 个字符"做指纹，而第 30~40 字常常正好撞上公式（接口是 `\[…\]`、页面是排版结果），指纹一比就判成"新消息"，于是同一段内容正文里有、文末又抄一遍。

现在指纹只留**汉字 / 字母 / 数字的前 20 字**，公式和标点写法不同也能认出是同一条。

附录本身仍然保留——接口真的缺的那条（实测里 4 条中有 1 条确实缺）会照旧附在文末，并且标题会写明来源，提示里说明"这节的公式是页面排版结果，不是 LaTeX 原文"。

## 三、格式标记升到 md-v5

升级后第一次运行会把全部会话重导一遍（只这一次），之后恢复按 `update_time` 的增量。

## 四、怎么跑

1. 登录面板，进入聊天页
2. `F12` → Console → 粘贴脚本 → 回车
3. 右上角浮窗：桥接在跑就直接写；否则选**上次同一个**导出文件夹
4. 保持"跳过已抓过的会话"勾选，点开始

跑完看 `_诊断_导出.md` 的 `格式自检` 和 `取源规则` 两行。
