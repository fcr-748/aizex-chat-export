# 使用说明 v3.1（推荐）

## 相比 v3 修复了什么

1. **接口识别加固**：排除统计类 / 跨域接口；找到候选接口后先**重放验证一次**，返回的不是聊天数据就自动退回页面抓取。不会再出现把统计接口当成会话接口、导出大量 1KB 垃圾文件的问题。
2. **坏文件自愈**：扫描文件夹时自动识别无效文件（内容含统计接口返回值等），标记为"未导出"，本次运行会自动重新导出。
3. **JSON 从文件重建**：每次结束从所有有效 `.md` 重建 `aizex_export.json`，之前导出的好数据会补回 JSON，索引完整合并。

## 步骤

1. 用 Chrome / Edge 登录面板，进入聊天页面（**先刷新页面**，清掉旧面板）
2. 按 `F12`，点 **Console（控制台）**
3. 打开 `src/aizex_export_v31_snippet.js`，全选复制全部内容
4. 粘贴进控制台，按回车
5. 右上角面板：
   - 点 **选择保存文件夹**，选你上次用的同一个文件夹
   - 保持"跳过已导出的会话"打勾
   - 想重新导出某些已导出但开头缺失的会话，在"强制重导关键词"里填标题关键词（如：旅行）
   - 点 **开始导出**
6. 面板会先显示："面板共 N 个会话；文件夹里已有 M 个文件（其中 X 个是无效文件，会自动重新导出）；本次需导出 K 个"

## 提示

- 保持标签页在前台
- 中途"登录失效 / 被踢"：重新登录后重跑即可，自动接续
- 如果显示"页面抓取模式"，说明只能慢慢抓，每次跑一批、跑完再跑，符合"逐步存档"
