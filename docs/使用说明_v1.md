# 使用说明 v1（初版）

> 当前推荐使用 v3.1：`src/aizex_export_v31_snippet.js`。本文件为 v1 初版说明，仅作历史参考。

## 步骤

1. 用 Chrome / Edge 登录面板，进入聊天页面
2. 按 `F12`，点 **Console（控制台）**
3. 打开 `src/aizex_export_snippet.js`，全选复制全部内容
4. 粘贴进控制台，按回车
5. 按右上角绿色面板：选文件夹 → 开始导出

## 导出内容

- `aizex_export.json`：完整备份
- `00_索引.md`：所有聊天目录
- 每个聊天一个 `.md`

## 已知问题（v2/v3/v3.1 已修复）

- 可能提前停止，漏掉部分会话
- 早期消息被折叠时可能抓不全开头
- 索引 / JSON 在重复运行时可能被覆盖

## 提示

- 保持标签页在前台
- 脚本只在本地浏览器运行，不上传数据
