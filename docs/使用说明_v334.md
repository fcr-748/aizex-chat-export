# 使用说明 v3.34（新对话 vs 有更新，分开报清楚）

脚本文件：[src/aizex_export_v334.js](../src/aizex_export_v334.js)

## 一、先回答那个关键疑问

**面板里新出现的对话，每次运行都会抓**——和更新时间没关系。

判断是两套条件，各管一件事：

| 条件 | 管什么 |
| --- | --- |
| 磁盘上有没有这个会话的文件 | **新对话**：没有 → 一定抓 |
| 接口给的 `update_time` 和台账里记的一不一样 | **老会话**：时间变了 → 重抓（内容更新过） |

所以就算接口没返回 `update_time`（状态栏会提示），新对话照样会被抓；那种情况只是"判断不了老会话有没有被改"。

## 二、现在会把"为什么抓这一条"分开报

以前只报一个总数，看不出在抓什么。现在分四类：

| 分类 | 含义 |
| --- | --- |
| 新对话 | 磁盘上根本没有这个会话的文件 |
| 面板上有更新 | 已经抓过（格式也是最新的），但接口的更新时间变了 |
| 旧格式升级 | 有文件，但是老版本写的（缺格式标记），需要重导一次 |
| 关键词强制 | 命中你填的"强制重导关键词" |

面板状态栏会这样写：

```
本次要抓 12 条：新对话 3 条、面板上有更新 4 条、旧格式升级 5 条
· 新对话：旅行路线、概率论作业、货基收益
· 有更新：货币与通胀解析（2026-05-22 19:15）、哲学论文（2026-09-01 08:13）
```

`_诊断_导出.md` 里新增「本次抓取明细」表：

| 标题 | 为什么抓 | 面板更新时间 | 台账里原来的时间 |
| --- | --- | --- | --- |
| 货币与通胀解析 | 面板上有更新 | 2026-05-22 19:15 | 2026-05-20 11:02 |

旧格式升级那一类只报数量（可能一次几百条），不逐条列。

## 三、不需要重跑就能看到

这一版只改"怎么报"，不改导出格式（格式标记仍是 `md-v7`），所以已有文件不用重导；下一次运行就能看到新的分类提示。
