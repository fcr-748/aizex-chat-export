# 使用说明 v3.31（控制台脚本，当前推荐版本）

脚本文件：[src/aizex_export_v331.js](../src/aizex_export_v331.js)

这一版是 v3.30 的收尾：修两个会"吞内容"和"认错结构"的坑，并把还没支持的结构记下来。

## 一、放大括号被吞掉

KaTeX 把放大括号（`\left( … \right)`、`\bigl|` 这类）放在 `.delimsizing` 里，而且是一串"拼片"字符（`⎛⎜⎝`）。我上一版把这些当成排版辅助元素跳过了，结果还原出来的公式**丢了括号**。

现在：

- `.delimsizing` 当可见内容处理
- 拼片字符拼回真实括号：`⎛⎜⎝` → `(`、`⎡⎢⎣` → `[`、`⎧⎨⎩` → `{`（上下片映射到同一个字符时合并）
- 普通连续括号（`))`）不受影响

## 二、加一道保险：括号覆盖检查

还原结果的括号必须覆盖页面上看到的括号。页面有 `)` 而还原结果里没有，就说明结构认错了——这时**不写进 `$…$`**，退回普通文字，宁可朴素也不让错误公式混进文件。

## 三、把"还认不出的结构"记下来

以前只留前 8 个样本，往往全是同一种结构（比如全是分数），真正认不出的那种反而没被记到。现在**按结构指纹去重**地留样本（最多 10 个），并在 `_诊断_导出.md` 里直接列出还没支持的结构：

```
还认不出的公式结构（下次照这个补规则）:
  - base|katex|katex-html|mord|mord mathnormal|sqrt|sqrt-sign|vlist|vlist-r|vlist-t
```

下次跑完把这行和 `_数学节点样本.html` 发我，我照着补根号、单边上下标这些。

## 四、格式标记不变（仍是 md-v6）

这一版没有改导出的**格式**，只改了页面版公式的还原质量，所以**不需要为了它重跑全量**：已有的 md-v6 文件照样有效。

想让旧文件里的附录也跟着变好，有两个办法：

1. 下次跑的时候**取消勾选**"跳过已抓过的会话"，让它重抓一遍（会花时间）
2. 或者只在需要时对个别的会话用"强制重导关键词"重抓（推荐）
