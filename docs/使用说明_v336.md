# 使用说明 v3.36（界面图标不再当成会话图片）

脚本文件：[src/aizex_export_v336.js](../src/aizex_export_v336.js)

## 一、你看到那张紫色学位帽是怎么进来的

那不是对话里的图，是**面板界面自己的图**（侧边栏 "Scholar GPT" 的模型 Logo）。

原因很具体：抓页面图片时，代码会先找会话容器 `[data-testid="conversation"]`；这个面板的 DOM 结构跟标准 ChatGPT 不完全一样，找不到的时候就**退化成"扫整个 body"**——于是侧边栏的 Logo、书签图标、消息下方的按钮图标全被当成会话图片收集，最后堆在文末「附：本会话涉及的图片」里。

## 二、这一版的过滤

| 规则 | 说明 |
| --- | --- |
| 只从消息节点里捞 | 改成扫 `[data-message-author-role]`（就是对话气泡），不再扫整个页面 |
| 小图标过滤 | 真实像素或声明尺寸 ≤48px 的图跳过（Logo、图标基本都在这个范围） |
| 名字过滤 | URL 里带 `logo` / `icon` / `avatar` / `emoji` / `sprite` / `brand` / `scholar` 等的跳过 |
| 位置过滤 | 位于 `button` / `nav` / `aside` / `header` / `footer` / 按钮角色元素里的图跳过 |

对话里真正的图片（你上传的截图、AI 生成的图）都远大于 48px、在消息体内、URL 也不带这些字样，所以不受影响。

## 三、格式标记升到 md-v8

附录内容会变，升级后第一次运行会重导一遍（只这一次）。

**注意**：如果你此刻正在跑（进度才几条），这次跑出来的是 md-v7，里面还会带这类界面图；重载扩展后用 v3.36 重跑一遍，这一趟就是干净的了。
