# 使用说明 v3.27（控制台脚本，当前推荐版本）

脚本文件：[src/aizex_export_v327.js](../src/aizex_export_v327.js)

## 一、这一版修了什么

### 1. 公式不再被拼成三份

面板把数学公式渲染成三层：TeX 源码、可见层、无障碍层。旧版对"没有代码块/表格/列表"的消息走 `innerText` 兜底，三层一起抓，于是同一个公式在导出文件里出现两三遍：

```
Vλi={x∈Pn:Ax=λix}.V_{\lambda_i}=\{x\in P^n:Ax=\lambda_i x\}.Vλi={x∈Pn:Ax=λi x}.
```

现在识别 `.katex` / `mjx-container` / `<math>` 节点，优先取里面的 `<annotation>` 原始 TeX，统一写成 `$…$`（行内）和 `$$…$$`（独立行），其余渲染层跳过。

### 2. 不再"空格变换行"

`innerText` 返回的是"排版后的文字"：浏览器为了适应宽度自动折的行，也会变成换行符。粘贴进去的表格、长句就这样被拆成了一行几个字。

现在按 DOM 结构换行：只有块级元素、`<br>` 才产生换行，文字里的空格就是空格。

### 3. 结构找回一点

标题（`<h2>`/`<h3>`）写成 `###`，引用写成 `>`，分隔线写成 `---`；表格、代码块、列表沿用原有处理。

### 4. 面板塞的图片 JSON 不再进正文

`{"asset_pointer":"file-service://…"}` 那一大坨被替换成 `［图片］`，图片指针照旧收集到文末的图片清单里。

## 二、更新时间与增量

新增 `_同步台账.json`：记录每条会话在面板上的 `update_time`（来自接口 `/backend-api/conversations`）和上次导出结果。

- 每条 `.md` 的文件头多了 `> 最后更新: 2026-10-08 12:30`
- `00_索引.md` 每条后面标了最后更新时间
- `manifest.json` 每条多了 `updated` 字段
- **下次运行时，面板上"更新过"的会话会自动重抓，没更新的照旧跳过**（不用再全量重跑）

如果接口没返回 `update_time`，脚本会在状态栏和诊断里明说"这次拿不到更新时间"，此时只能按已有文件跳过。

## 三、格式升级：第一次会重导一遍

文件头的 `保真度` 标记从 `md-v2` 升到 `md-v3`。旧格式的 `.md` 会被自动重导一次（公式去重后正文本来就会变短，所以这次不看字数保护，直接覆盖）。往后就正常增量了。

## 四、怎么跑

同之前的版本：

1. 登录面板，进入聊天页（左侧能看到会话列表）
2. `F12` → Console → 粘贴脚本 → 回车
3. 右上角浮窗：本地桥接在跑就直接写；否则选**上次同一个**导出文件夹
4. 确认勾选"跳过已抓过的会话"，点开始

跑完看一眼这几处：

- 状态栏会写"面板上有更新、本次会重抓 N 条: …"
- `_同步台账.json`：台账有没有正常长出来
- `_诊断_导出.md` 里的"格式自检"：数学节点 N 个（取到原始 TeX M 个）。如果 M 明显小于 N，把这行发我，我按真实 DOM 补规则
