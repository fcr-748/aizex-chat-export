# 使用说明 v3.30（控制台脚本，当前推荐版本）

脚本文件：[src/aizex_export_v330.js](../src/aizex_export_v330.js)

## 一、接口为什么漏消息：改用 current_node

接口返回的会话数据里有一张 `mapping`（消息节点图）和一条 `current_node`（**页面上当前显示的那条**）。

- 旧写法：从 `create_time` 最大的那条往上回溯到根。遇到"重新生成 / 编辑过"的会话，这条链会走到**另一个分支**上去
- v3.30：优先从 `current_node` 往上回溯；数据里没有 `current_node` 时才退回旧写法

后果本来就看得见：接口少了消息 → 只能靠页面版补到文末附录 → 页面版拿不到公式原文 → 公式变成排版结果。这条修好之后，附录和公式变形的部分都会明显变少。

## 二、页面版公式：按 KaTeX 的 HTML 结构反推

面板的 KaTeX 只输出 HTML（没有 mathml / annotation 层），而且分数、上下标在里面是**绝对定位的行**，DOM 里的文字顺序不是你看到的顺序。实测的结构是：

```html
<span class="mfrac"><span class="vlist-t vlist-t2"><span class="vlist-r"><span class="vlist">
  <span style="top:-2.314em">…R…</span>      <!-- 分母（位置低） -->
  <span style="top:-3.23em">…分数线…</span>
  <span style="top:-3.677em">…1…</span>      <!-- 分子（位置高） -->
```

所以把文字直接拼起来会得到 `MΔM`（分母在前、分子在后）这种怪东西。v3.30 按 `top` 值排序还原：

| KaTeX 结构 | 还原成 |
| --- | --- |
| `.mfrac` 的几行 | `\frac{分子}{分母}`（按 top 排序，滤掉分数线那一行） |
| `.msupsub` 的两行 | `^{上标}_{下标}` |
| `.mord.text` / `cjk_fallback` | `\text{中文}` |
| 普通符号、运算符 | 原样拼接（`mspace` / `strut` / 分数线这些排版用的跳过） |
| 多个 `.base` | 换行（长公式被 KaTeX 折成多行的情况） |

**认不出来的结构**（根号、只带一边的上下标、强调号等）不硬塞 `$…$`，直接当普通文字写——宁可朴素，也不要在预览里出现散架的假公式。

跑完在 `_诊断_导出.md` 里能看到比例：

```
格式自检: 数学节点 2506 个（接口原文 2400 个，按 HTML 结构还原 90 个，只能退回文字 16 个）
```
