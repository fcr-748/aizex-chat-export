# 使用说明 v3.26（控制台脚本，推荐版本）

脚本文件：[src/aizex_export_v326.js](../src/aizex_export_v326.js)

## 一、怎么跑

1. 用 Chrome 或 Edge 登录面板，进入聊天页面，确认左侧能看到会话列表
2. 按 `F12` → **Console（控制台）**
3. 打开脚本文件全选复制，粘贴到控制台，回车
4. 页面右上角出现浮窗，按提示操作：
   - 若本机在跑本地桥接（`127.0.0.1:8787`，见 [tools/aizex_bridge_server.js](../tools/aizex_bridge_server.js)），脚本自动连上，直接写进上次那个导出文件夹
   - 桥接不可用就点"选择保存文件夹"，选你上次用的**同一个**文件夹（增量续跑靠它）
5. 点"开始导出"，**保持标签页在前台**

中途随时可以停：重新粘贴运行会接着上次的进度，不会从头来。

## 二、这一版解决了什么

| 能力 | 说明 |
| --- | --- |
| 折叠全部展开 | 面板把长会话的早期消息折叠成"点击展示全部折叠的消息（共 N 轮）/ 全部展开 / 继续阅读"。脚本点的是面板**真实控件**（`span.nextc-batch-trigger-action`、`span.nextc-batch-trigger-title`、`button.A_HxFq_toggleControl`），一层层点到没有折叠块为止 |
| 完整性自检 | 读面板自己标的"共 N 轮"，跑完把"预期条数 / 实际条数 / 是否完整"写进 `_诊断_导出.md`；不完整的会自动再抓一次 |
| 双源合并 | 后端接口（`/backend-api/conversation/<id>`）和页面展开各抓一份，取更全的，另一份独有的消息附在文末 |
| 断点续跑 | `_已完成清单.txt` 记录已按新机制抓过的会话；重启只补没抓全的 |
| 内容保护 | 新抓的结果比已有文件少时，保留已有文件 |
| 格式保真 | 代码块带语言围栏、表格转标准 Markdown、列表按层级缩进、行内格式保留，界面按钮文字剔除 |
| 图片下载 | 收集会话里的图片，尝试下载到 `images/`，下不到的保留指针 |
| 按 ID 去重 | 会话改过标题也不会变成两份；重复文件挪进 `_duplicates/`（不删除） |
| 归档包 | 结束时生成 `manifest.json` + `归档说明.md` + `归档_日期-时间.zip` |
| 设置界面 | 浮窗里可调：是否下载图片、是否生成归档包、每条会话间隔（0-3000ms），自动记住 |

## 三、已知限制（如实说明）

1. 面板改版可能导致选择器失效。浮窗提示"没找到会话列表 / 折叠控件"就是这种情况，需要更新脚本
2. 图片能不能下载取决于面板是否暴露文件端点；下不到就只留指针
3. 公式（LaTeX）目前按文本保存，没有转成 `$…$`
4. 目前只支持 ChatGPT 前端镜像这一类站点；NextChat / LobeChat / Open WebUI 需要另加适配
5. 时间字段来自正文文本，只能粗略排序

## 四、跑完检查这几个文件

- `_诊断_导出.md`：每条会话抓了多少条、点了多少次展开、在哪一步停下
- `_待补清单.txt`：标了"不完整"的会话，重新跑一次通常会补上
- `_已完成清单.txt`：断点续跑的进度记录
